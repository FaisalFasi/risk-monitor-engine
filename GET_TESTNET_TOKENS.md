# 🪙 How to Get Testnet NEAR Tokens

## ❌ The Problem

When connecting your wallet, you see:
```
Something went wrong
Sender faisalrehman.testnet does not have enough balance 0 
for operation costing 0.0000420638964564
```

**Why:** Your testnet account has 0 NEAR tokens. Even connecting requires a small gas fee (~0.00004 NEAR).

---

## ✅ Solution: Get Free Testnet Tokens

### **Option 1: NEAR Testnet Faucet (Recommended)**

1. **Go to the official NEAR faucet:**
   ```
   https://near-faucet.io/
   ```

2. **Enter your testnet account:**
   ```
   faisalrehman.testnet
   ```

3. **Click "Get Tokens"**
   - You'll receive: **10 NEAR testnet tokens**
   - Instant delivery (5-10 seconds)

4. **Verify you received tokens:**
   - Go to: https://testnet.nearblocks.io/address/faisalrehman.testnet
   - Should show: ~10 NEAR balance

5. **Try connecting wallet again:**
   - Should work now! ✅

---

### **Option 2: Alternative Faucet**

If the first faucet doesn't work:

1. **Go to:**
   ```
   https://testnet.mynearwallet.com
   ```

2. **Login to your account:**
   - Use your existing testnet account
   - Or create a new one (comes with tokens)

3. **Use built-in faucet:**
   - Look for "Get testnet tokens" or "Faucet" button
   - Request tokens

---

### **Option 3: Create New Testnet Account (With Free Tokens)**

If you want to start fresh:

1. **Go to Meteor Wallet:**
   ```
   https://wallet.meteorwallet.app
   ```

2. **Create a new testnet account:**
   - Click "Create Account"
   - Choose a username
   - Select "Testnet" network
   - **New accounts automatically get 200 NEAR testnet tokens!**

3. **Use this new account:**
   - Connect with this account instead
   - Will have plenty of balance for testing

---

## 🔍 **Verify Your Balance**

**Check on NearBlocks:**
```
https://testnet.nearblocks.io/address/YOUR_ACCOUNT.testnet
```

**Should show:**
```
Balance: 10.00 NEAR (or more)
```

## 💡 **Why This Happens**

### **NEAR Transaction Costs:**

Every action on NEAR requires gas:
- **Connect wallet:** ~0.00004 NEAR
- **Token swap:** ~0.001-0.003 NEAR
- **Transfer tokens:** ~0.0001 NEAR

**Testnet tokens are FREE** - just get them from a faucet!

---

## 🚀 **After Getting Tokens**

1. **Connect wallet:**
   - Click "Connect Wallet" in your app
   - Select "Meteor Wallet"
   - Should work now! ✅

2. **Test a swap:**
   - Try swapping NEAR → USDC
   - Should complete successfully

3. **View transactions:**
   - Check transaction history
   - See completed swaps

## 🆘 **Still Having Issues?**

### **Issue 1: Faucet says "Already claimed"**

**Solution:**
- Faucets have limits (once per day/IP)
- Try from different network/device
- Or use Option 3 (create new account)

### **Issue 2: Tokens not showing up**

**Solution:**
- Wait 30 seconds and refresh
- Check on NearBlocks explorer
- Make sure you're on testnet (not mainnet)

### **Issue 3: Wrong network**

**Solution:**
- Make sure your wallet is set to "Testnet"
- Check URL: should have "testnet" in it
- Your account should end with .testnet
